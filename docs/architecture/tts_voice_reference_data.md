# AI Hub 다화자 음향 기준과 엄마 음성 선정 계약

## 상태

Accepted · 2026-08-18

## 목적

엄마 역할 음성을 한 사람의 목소리와 비슷하게 복제하지 않고, 실제 50·60대 한국인 여성
다수의 음향 분포와 사용자 청취 평가를 함께 사용해 선정한다. AI Hub 원본은 로컬 분석 입력으로만
사용하고 저장소에는 익명 집계 결과만 남긴다.

이 기준은 음높이 하나로 나이·성별·역할을 자동 판정하는 모델이 아니다. 생성된 후보가 실제
참조 집단에서 지나치게 벗어나는지를 거르는 음향 검사이며, 따뜻함·자연스러움·엄마 역할 적합성은
사용자가 음성을 듣고 최종 결정한다.

## 사용 데이터와 범위

- 데이터셋: AI Hub `71558`, 중·노년층 한국어 방언 데이터
- 승인 및 분석일: 2026-08-18
- 분석 묶음: Validation · 제주도 · 1인 발화 따라 말하기
- 라벨과 음성: 각각 4,498개가 일대일로 존재함을 확인
- 대상: 녹음 시점 기준 50~69세 여성, 한 사람만 녹음된 파일
- 대상 화자: 50대 36명, 60대 19명, 총 55명
- 균형 표본: 화자별 최대 3개, 총 153개

공식 데이터 설명: [AI Hub 데이터셋 71558](https://aihub.or.kr/aihubdata/data/view.do?currMenu=115&topMenu=100&dataSetSn=71558)

승인된 `다화자 음성합성 데이터(542)`와 `감성 및 발화스타일 동시 고려 음성합성
데이터(71349)`도 구조를 확인했다. 그러나 경량 샘플은 각각 30대 남성 한 명, 20~30대 화자
일곱 명으로 구성돼 엄마 역할 연령 기준에는 사용하지 않았다. 연령이 맞지 않는 자료를 결과에
섞지 않는 것이 데이터 선택 계약이다.

## 집계 계약

1. 라벨의 성별, 생년, 녹음일, 단일 화자 여부를 필수 필드로 검증한다.
2. 녹음 연도에서 출생 연도를 빼 녹음 당시 나이를 구한다.
3. 한 파일에 두 사람 이상이 있으면 서로 다른 목소리가 섞이므로 제외한다.
4. 각 화자의 파일을 고정 SHA-256 순위로 정렬하고 최대 3개만 선택한다.
5. 각 파일에서 Praat 자기상관 방식으로 기본 주파수(F0)의 중앙값을 구한다.
6. 파일 수가 많은 화자가 결과를 지배하지 않도록 화자별 중앙값을 먼저 구한다.
7. 화자 55명의 중앙값 분포에서 25%, 50%, 75% 지점을 집계한다.
8. 대상 화자가 20명 미만이면 통계가 충분하지 않은 것으로 보고 분석을 중단한다.

고정 순위는 무작위로 매번 다른 파일을 뽑지 않으면서도 파일명의 사전식 순서에 치우치지 않기
위한 재현 가능한 균형 표본 방식이다. 화자의 감정이나 역할을 추측하는 규칙은 사용하지 않는다.

## 분석 결과와 설계 변경

화자별 중앙 F0 분포는 다음과 같다.

| 지점 | F0 |
|---|---:|
| 25% | 187.1 Hz |
| 중앙 | 203.3 Hz |
| 75% | 229.2 Hz |

기존 `natural_everyday` 후보의 196.9 Hz는 이 범위 안에 있다. 반면 음높이를 강제로 낮춘
`natural_everyday_contralto`의 162.4 Hz는 25% 지점보다 낮았고, 사용자 청취에서도 어색하다고
판정됐다. 따라서 “나이가 들어 보이게 하려면 음높이부터 계속 낮춘다”는 방향을 폐기한다.

후속 후보는 187.1~229.2 Hz 범위를 자동 승인 기준이 아닌 검사 범위로 사용한다. 연령감은
억지로 낮은 음정보다 다음 속성으로 설계한다.

- 편안한 중간 음높이
- 따뜻하고 충분한 성량감
- 중저역의 둥근 공명
- 안정된 호흡과 속도
- 과하지 않은 자연스러운 억양
- 성우·아나운서처럼 꾸민 말투가 아닌 생활 대화

이 원칙으로 생성한 첫 세 후보의 결과는 다음과 같다.

| 후보 | 중앙 F0 | 음향 검사 | 선정 상태 |
|---|---:|---|---|
| `reference_warm_everyday` | 168.3 Hz | 가운데 50% 범위 아래 | 상대적으로 가장 나아 개선 기준으로 유지·미승인 |
| `reference_calm_reassuring` | 197.6 Hz | 범위 안 | 사용자 청취 거절 |
| `reference_gentle_lived_in` | 213.3 Hz | 범위 안 | 사용자 청취 거절 |

검사 범위 밖이라는 이유만으로 첫 후보를 삭제하거나 실패로 확정하지 않는다. 음향 검사는 사람의
청취를 대신하지 않기 때문이다. 실제 청취에서는 세 후보가 모두 만족스럽지 않았고 첫 후보가
상대적으로 가장 낫다는 평가를 받았다. 따라서 첫 후보를 최종 승인하지 않고 다음 개선의 부모
후보로만 유지한다. 범위 안에 있던 나머지 두 후보는 사용자 평가에 따라 거절했다. 이 결과는
음높이 범위 일치가 음색·말투 품질을 보장하지 않는다는 근거다.

## 개인정보와 라이선스 경계

- AI Hub 원본 WAV, JSON, 대사, 원본 파일명, 화자 식별자는 Git에 커밋하지 않는다.
- `data/aihub/`는 `.gitignore`로 차단한다.
- 저장소에 남기는 결과에는 화자 ID, 원본 파일명, 대사, 음성이 없다.
- 화자별 수치도 남기지 않고 55명의 집계 통계만 기록한다.
- 특정 화자를 찾거나 다시 식별하거나 한 사람의 음색을 복제하는 데 사용하지 않는다.
- 원본 데이터를 재배포·판매·외부 반출하지 않는다.
- 데이터 활용 결과에는 NIA·AI Hub 출처를 표시한다.
- 개인정보가 발견되면 분석을 중단하고 AI Hub 절차에 따라 신고·삭제한다.

집계 결과의 두 SHA-256 값은 라벨 내용과 선택 음성이 같은 입력이었는지 검증하기 위한
무결성 지문이다. 이 값만으로 원본 음성이나 화자 정보를 복원할 수 없다.

## 재현 명령

원본은 저장소 밖의 승인된 로컬 경로에 두고 다음 명령을 실행한다.

```bash
python -m scripts.analyze_aihub_mature_female_reference \
  --label-root /absolute/private/path/to/labels \
  --audio-root /absolute/private/path/to/wav \
  --output artifacts/tts-role-auditions/cast-v2/family-mother-reference/\
aihub-71558-jeju-validation-v1.json
```

출력 파일이 이미 있으면 덮어쓰지 않고 중단한다. 기존 결정을 바꾸려면 입력 범위, 계약 버전,
변경 이유를 먼저 검토한 뒤 새 결과 파일로 기록해야 한다.

참조 기준을 사용하는 후보 생성 명령은 다음과 같다.

```bash
python -m scripts.generate_qwen_mother_voice_design_auditions \
  --output-dir /absolute/private/path/to/mother-auditions \
  --device mps \
  --dtype bfloat16 \
  --design-id reference_warm_everyday \
  --design-id reference_calm_reassuring \
  --design-id reference_gentle_lived_in \
  --acoustic-reference artifacts/tts-role-auditions/cast-v2/\
family-mother-reference/aihub-71558-jeju-validation-v1.json
```

## 용어 Q&A

### Q. 원천 데이터와 라벨 데이터는 무엇이 다른가요?

원천 데이터는 실제 WAV 음성이다. 라벨 데이터는 그 음성의 녹음일, 화자 연령대, 성별, 발화
형태처럼 분석에 필요한 설명을 담은 JSON이다. 파일명이 일치해야 같은 기록으로 취급한다.

### Q. F0와 피치는 같은 말인가요?

F0는 성대가 1초에 진동하는 기본 주파수를 Hz로 나타낸 측정값이다. 사람이 느끼는 음높이를
설명하는 중요한 요소지만, 공명·억양·속도·발성까지 포함하는 전체 인상과 같지는 않다.

### Q. 중앙값은 왜 사용하나요?

값을 크기순으로 놓았을 때 가운데 값이다. 한두 구간에서 음높이 측정이 튀어도 평균보다 덜
흔들리므로 자연 발화의 대표값에 적합하다.

### Q. 25%와 75%는 무엇인가요?

화자별 대표값을 작은 순서로 놓았을 때 각각 전체의 4분의 1과 4분의 3이 되는 지점이다.
둘 사이는 가운데 50% 화자가 놓이는 범위다. 정상·비정상을 판정하는 의학적 기준은 아니다.

### Q. SHA-256은 무엇인가요?

파일 내용을 입력해 64자리 16진수로 만드는 디지털 지문이다. 내용이 한 바이트라도 달라지면
값이 달라져 같은 입력을 사용했는지 검증할 수 있다. 암호화된 원본이나 파일명은 아니다.

### Q. 재식별은 무엇인가요?

익명 처리된 화자 ID, 음성 특징, 다른 정보를 결합해 실제 사람이 누구인지 찾아내려는 행위다.
이 프로젝트는 재식별을 금지하고 개인 단위 결과를 저장하지 않는다.

### Q. 왜 방언 데이터를 최종 TTS 학습에 바로 사용하지 않나요?

이번 목적은 모델 학습이나 음성 복제가 아니라 실제 중년 여성의 음향 범위를 교차 확인하는
것이다. 제주 방언 억양이 최종 말투에 들어가지 않도록 원본 음성을 모델 입력이나 복제 기준으로
사용하지 않고 F0 집계에만 사용한다.
