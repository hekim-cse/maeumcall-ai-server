# A/S 관찰 장소와 후속 사건 범위 평가 결과

사용자가 [SQ01~SQ09 검토표](nlu_safety_source_scope_pair_review.md)를 채택했다. SQ03~05의 후보는 모두 보류, SQ07의 전기담요 열선과 SQ08의 믹서기 받침은 승인으로 확정했다. [정답 JSON](../../evals/structured_nlu/data/ai_heldout/as-safety-source-scope-sq-reviewed.v1.json)과 채점 코드를 `2e6d3f8`에 고정하고 같은 사건과 후보 18개를 기존 역할 규칙과 새 범위 규칙에 입력했다. 검수 라벨은 채점에만 사용했다.

| 지표 | 기존 역할 규칙 | 새 범위 규칙 |
| --- | ---: | ---: |
| 근거 없는 후보 오승인 | 1/14 | 0/14 |
| 실제 출처 누락 | 2/4 | 2/4 |
| 두 후보를 모두 맞힌 발화 | 6/9 | 7/9 |
| 오류 | 0/18 | 0/18 |

- **SQ01 오승인 제거:** 지하 복도는 사건이 관찰된 장소이며 물리 출처가 아니다. 새 규칙은 기기·부위 근거가 없는 위치 후보를 보류했다.
- **SQ08 누락 복구:** 믹서기 받침이 갈라진 사건과 소리의 출처 미확인을 분리했다. 변화 주어를 실제 발생 대상으로 반환했다.
- **SQ07 새 누락:** 전기담요 열선은 출처 정답이지만, 새 규칙에서 기기·부위 명사 머리말 목록에 없어 보류했다.
- **SQ02 누락 유지:** 연기와 별개 소리의 범위는 분리했으나, Kiwi가 `송풍구`를 `송`과 `풍구`로 나눴다. 새 규칙이 마지막 형태소만 목록과 대조해 온풍기 송풍구를 보류했다. 기존 규칙은 후속 출처 미확인 표현 때문에 보류했다.

같은 사건, 대상 생략, 여러 사건을 함께 정정하는 SQ03~05는 두 버전 모두 보류했다. 관찰 장소 오승인은 줄었지만 누락 총수는 줄지 않았다. 다음 개선은 명사 목록을 관찰 사례마다 늘리는 대신, 원문 복합명사 경계와 부위 근거를 결합해 기기 출처를 보존하는 방향이 적절하다. 새 개발 후보는 별도 표본으로 검증한다.

[결과 JSON](../../evals/structured_nlu/results/as-safety-source-scope-sq-evaluation.v1.json)은 Kiwi 0.23.2 및 사전 모델 0.23.0에서 `python -m experiments.as_safety_source_scope_evaluation`으로 재생했다. 입력 SHA-256은 `35ce21d331f7c8fc39f2818f42fdd84751f1dd9d5d78087c36a1ee39f744036b`다. AI 작성·사용자 검수 오프라인 9개 발화이며 사건·후보는 사전에 고정했다. 서비스 정확도나 안전 경로 성능은 평가 범위 밖이다.
