# A/S 출처 근거 표시 번호 대조

[v20](nlu_safety_eb_single_source_v20_result.md)에서 Qwen은 네 후보 모두에 사건이 있던 2번을 골랐다. 사건 문장을 따라갔는지, 표시 숫자 2가 계속 선택되는지 구분하기 위해 동일한 네 요청에서 표시 번호 1과 2를 교환한다. 문장 내용과 배치, 사건·후보 구절, 질문, JSON 스키마와 서버·모델·생성 설정은 유지한다. 사건 및 후보의 번호 참조도 새 표시 번호와 일치시킨다.

정답 출처 1건은 새 번호 1, 나머지 세 건은 공란이다. 숫자 2와 사건의 새 표시 번호 1 선택을 따로 센다. 1이 반복되면 고정 숫자 2 설명이 약해지지만, 사건 문장과 원래 두 번째 위치는 함께 남으므로 사건 의미와 위치 편향은 분리할 수 없다. 2가 반복되면 변경된 사건 표시를 따라가지 않았다는 관찰이다. 혼합이나 전건 보류도 그대로 보고한다.

코드와 요청 해시를 첫 생성 전에 고정한다. 전송·계약 오류 시 중단하고 재시도하지 않는다. 기존 v20은 과거 실행을 참조한다. 네 사례 모두 기노출 개발 진단이다.
