# A/S 위험 출처 주체 구간 검토 초안

**상태: AI 작성·사용자 미검수 초안.** 기존 RE/V 발화 24건에서 위험 사건의 주체를 가리키는 원문 구간을 찾기 위한 작업지다. 이 표의 주체 구간, 연결 종류, 대안은 아직 사용자가 검수하지 않았다. **모델 입력이나 평가 정답으로 사용하지 않는다.** 기존 관계 정답은 이미 검수된 개발 사례의 참조값일 뿐이며, 이번 주체 구간의 정답 확정을 뜻하지 않는다.

`주체 구간`은 위험이 발생한 제품·부품·장소 또는 이를 가리키는 표현을 원문에서 연속으로 인용한 것이다. `문장`은 [기존 진단의 문장 분리 방식](../../scripts/probe_as_safety_clause_index.py)으로 매긴 1부터 시작하는 번호다. 단일 구간을 정하기 어려우면 `null`로 두고 후보를 검토 메모에 적었다. `current`·`other`·`unknown`은 [기존 RE 데이터](../../evals/structured_nlu/data/ai_heldout/as-safety-relation-fresh-reviewed.v1.json)와 [V 데이터](../../evals/structured_nlu/data/ai_heldout/as-safety-relation-v2-fresh-reviewed.v1.json)의 관계 참조값이다. 단, V04는 [이번 진단 입력](../../evals/structured_nlu/data/ai_heldout/as-safety-oracle-relation-spans-reviewed.v1.json)에서 접수 대상을 **토스터**로 지정해 `current`로 계산했다. 과거 V04의 `other` 정답과 점수는 바꾸지 않는다.

## 검수할 경계

1. **RE01·RE04·RE08·V07:** 부위·위치 표현이 접수 제품을 가리킨다는 연결을 원문만으로 확정할지 확인한다.
2. **RE06:** 사건 발생 여부와 위험 출처가 동시에 불확실하다. 단일 주체 `null`이 적절한지, 기존 `current` 관계를 조건부로 유지할지 확인한다.
3. **RE07·V09:** 둘 이상의 출처가 명시됐으나 선택되지 않았다. 주체 `null`과 후보 병기를 유지할지 확인한다.
4. **RE10:** 동일 모델이어도 친구의 제품은 별도 개체라는 기준을 확인한다.
5. **V03·V04:** 이번 진단의 접수 대상 지정과 기존 V04 정답의 차이를 유지한다.

검수 전에는 이 표를 JSON 정답 파일로 만들거나 모델에 제공하지 않는다. 검수 후에도 이 24건은 이미 모델에 노출된 개발 사례여서 공식 전체 정확도나 개선율의 근거가 될 수 없다.
