# NLU 의미 경계 새 발화 8건: 모델 실행 전 검토 초안

**상태:** AI 작성, 2026-11-05에 사용자에게 문장·행동·초점 필드 방향 8건 모두
탐색용으로 채택받음. 이후 SB02·SB04·SB06·SB08의 초점 값을 사용자 판단에
맞게 수정했고, 다른 필드에 대한 추가 수정 요청은 없었다. 공란 대조 사례 검토와
기존 D05·F23 판단 정리 전, Q4·Q5 모델 실행 전이다. 이 발화들은
`ai_assisted_unreviewed` 개발 자료다. 사람 작성 독립
test나 공식 정확도 근거가 아니다. 정규화된 **나머지 모든 필드**도 아직 확정되지
않았다. 가상의 주문과 행정·예약 상황만 사용했다.

처음에는 가능 조건 문의, 일반적인 온라인, 반복 요일을 각각 공란으로
제안했다. 사용자는 **SB02·SB04·SB06의 후보 값을 모두 지지**하고,
**SB08의 ‘매주 화요일’도 예약 의사와 날짜가 드러난다**고 판단했다.
따라서 처음 제안한 경계 정책과 후보 지시문은 이 검토 결과에 맞지 않는다.
이전 D05·F23 개발 사례와의 판단 차이는 별도 확인 중이며, 이전 실행 기록을
사후에 바꾸지 않는다. 새 정책 후보도 아직 서비스에 적용하지 않았다.

검토할 것은 **문장의 자연스러움, 행동 방향, 초점 필드가 지지되는지**다.
SB03은 질문형 재배달 요청으로, SB06은 일반 온라인을 정부24 경로로,
SB08은 반복 예약 의사와 날짜를 지지하는 것으로 탐색용 채택되었다.
수정할 ID와 문장·판단을 알려 주면 반영한다. 판단이 모호하면 보류할 수 있다.
사용자 검토 뒤에도 나머지 필드 초안을 따로 확인하고, 입력 파일·정책 후보·
실행 조건을 고정한 다음에만 모델을 실행한다. 모델에 한 번이라도 입력하면
이 사례들은 이후 독립 평가에 쓰지 않는다.
