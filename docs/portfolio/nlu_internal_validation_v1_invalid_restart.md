# 내부 validation 짝 비교 V1: 계획 재시작 검증 오류

> 상태: **무효·중단**. 2026-11-17(한국 시간) 실행한 V1의 8개 arm 결과를 정확도나 후보 선택에 사용하지 않는다. 원시 응답과 저널은 재실행에 섞지 않고 보존한다.

모델 호출 전 [V1 프로토콜](../../evals/structured_nlu/data/ai_heldout/nlu-internal-validation-pair-protocol.v1.json)(SHA-256 `b82b2fb694a3ec1d96816ebe923091c63aefadd3e02f5e951d1891ea0dd0e68a`)을 커밋하고 사전 검사를 통과했다. 동일 Q5 모델 해시, 로컬 이미지와 10GiB·2 CPU 서버 조건도 확인했다. 32쌍 중 4쌍, 총 8개 arm이 완료됐고 원시 응답 8개가 저장됐다. 저널 SHA-256은 `4a01d661b2f7f590216112d68d60771896552db753987cc18813892a29efb14e`다. 공개 결과 파일과 독립 검증 영수증은 생성되지 않았다.

8회 경계에서 계획된 `docker restart` 후 컨테이너 ID는 같고 `StartedAt`은 변경됐다. Docker의 실제 `RestartCount`는 0을 유지했으나 실행기는 1이 돼야 한다고 가정해 `planned restart identity differs`로 중단했다. 이는 점수를 발행하기 전에 실행 경계에서 확인한 도구 오류다. OOM이나 전송 실패가 원인이라는 근거는 없다.

수정 도구와 재실행 조건은 별도 커밋·새 V2 프로토콜로 고정한다. V1 저널이나 원문을 이어 쓰지 않고, 새로운 결과·저널·원문·검증 영수증 경로에서 32쌍을 처음부터 평가한다. V2 원시 응답의 독립 재생 검증이 통과하기 전에는 점수를 발표하지 않는다.
