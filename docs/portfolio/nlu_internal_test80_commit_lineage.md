# 내부 평가 커밋 이력 보존

PR #90은 `70cbb7c2b0a251188a71062922c5132393681cc7`로 스쿼시 병합됐다. 실행 전 동결한 프로토콜과 검증 영수증은 PR의 원래 커밋을 참조하므로, 스쿼시 커밋만 `main`에 남으면 나중에 그 커밋으로 작업 트리를 다시 만들 수 없다.

PR #90의 마지막 원래 커밋 `e5aaa643a9b4b3d1ee12f535b7b27b6e5a3b1532`와 스쿼시 커밋의 트리 SHA-1은 모두 `8a282c023d9e2426d9324857478fa2e209210bac`로 같았다. 이 문서의 PR은 두 이력을 **병합 커밋으로 연결**해 원래 후보·프로토콜·실행기 커밋을 `main`의 조상으로 보존한다. 평가 데이터, 원시 응답, 채점 결과는 다시 실행하거나 변경하지 않았다.

재검증할 때는 [평가 결과](nlu_internal_test80_verified_result.md)의 프로토콜과 영수증에 기록된 **원래 커밋 SHA**를 사용한다. 스쿼시 커밋은 그 커밋을 대신하지 않는다.
