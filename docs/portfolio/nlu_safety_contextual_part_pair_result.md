# A/S 부위 원문과 문맥 근거 대조 결과

사용자가 [CP01~CP09 검수표](nlu_safety_contextual_part_pair_review.md)의 문장과 판정을 채택했다. CP06·CP09 후보는 모두 보류하고 CP07의 인쇄기 집진판은 승인으로 확정했다. [정답 JSON](../../evals/structured_nlu/data/ai_heldout/as-safety-contextual-part-cp-reviewed.v1.json)과 채점 진입점은 첫 평가 전에 `9fa7b93`에 고정했다. 같은 관찰 사건과 후보 18개를 두 규칙에 입력하고, 고정 라벨은 채점에만 사용했다.

| 지표 | 기존 범위 규칙 | 새 부위 문맥 규칙 |
| --- | ---: | ---: |
| 실제 출처 누락 | 5/5 | 1/5 |
| 근거 없는 후보 오승인 | 0/13 | 0/13 |
| 두 후보를 모두 맞힌 발화 | 4/9 | 8/9 |
| 실행 오류 | 0/18 | 0/18 |

- **CP01 승인 회복:** `의류관리기 송풍구`의 원문 어절 전체를 알려진 부위와 대조했다.
- **CP02·CP03·CP08 승인 회복:** 절연판, 접점판, 왼쪽 차폐판이 앞 문장에서 기기의 부품으로 명시됐고, 사건 문장에서 같은 부위를 출처로 지목했다.
- **CP06·CP09 보류 유지:** 같은 이름의 두 차폐판은 구별되지 않고, 가림판 사례는 후속 발화가 해당 사건의 출처를 정정했다.
- **CP07 누락 유지:** 인쇄기 집진판은 문장에 직접 출처로 명시됐지만, 새 규칙에서 등록된 머리말 또는 앞 문장의 부품 관계를 확인하지 못했다. 정답을 고치거나 목록에 추가해 결과를 다시 계산하지 않았다.

이번 표본에서는 오승인 증가 없이 출처 누락이 네 건 줄었다. 이 규칙은 명시된 부분과 소수의 부품 관계 표현을 처리하므로, 제품 소속 전체나 실제 통화 성능을 평가한 결과는 아니다. 앞 문장 없이 처음 등장하는 부위와 더 다양한 부품 관계 표현은 검증 과제로 남는다.

[결과 JSON](../../evals/structured_nlu/results/as-safety-contextual-part-cp-evaluation.v1.json)은 Kiwi 0.23.2 및 사전 모델 0.23.0에서 `python -m experiments.as_safety_contextual_part_evaluation`으로 재생한다. 입력 SHA-256은 `89ab5b53c9cf4f7b4daa82fb4054ea210742c98b04f5baab5c521939fdc71a10`이다. 데이터는 AI 작성·사용자 검수 오프라인 9건이며 사건과 후보 구절이 주어진 조건이다.
