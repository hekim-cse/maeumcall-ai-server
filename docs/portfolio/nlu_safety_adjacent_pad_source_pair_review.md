PD07의 발생 상태는 미발생, 나머지 10건은 관찰로 제안한다. PD09는 조치가 완료되지 않아도 원문이 지정 사건의 출처를 직접 말했으므로 승인 정답을 유지한다.

- 후보 22개 중 승인 5개, 보류 17개다. 관찰 장소는 PD05-1·PD06-1·PD10-2·PD11-1이다. 다른 사건 출처는 PD11-2이고, 정확 구절 기준의 부분 인용은 PD01-2다.
- 채택 뒤 기존 결합 규칙과 새 규칙을 비교한다. PD01–PD03에서 각 변경을 따로 확인하고, PD04에서 결합 효과를 확인한다.
- ES 전체 후보는 이전과 같은 원문·후보 생성 설정·검수 사건으로 재평가한다. 전체 정확 선택과 ES14의 결정을 보고하고, ES02·ES06의 기존 정확 선택도 별도로 재확인한다.
