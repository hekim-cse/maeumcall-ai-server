# A/S E→B 후보별 관계 개발 진단 검토 초안

> 2026-11-22. **AI 작성·기노출 PC01·NC01의 파생 개발 사례**다. 사용자가 아래 네 쌍의 상태·근거 문장 번호를 모두 **개발용으로 채택**했다. 채택 전 모델 호출은 없었다. 기존 PC01·NC01의 B 정답을 새로운 관계 상태의 사용자 검수로 소급하지 않는다.

## 판단 기준

- `supported`: 이 **정확한 후보 구절 전체**가 위험 사건의 물리적 출처라는 근거가 원문에 있다.
- `unsupported`: 후보 구절이 현상 자체를 포함하거나 원문에 반하는 등, 정확한 구절 전체를 물리적 출처로 쓸 수 없다.
- `insufficient`: 물리적 출처일 가능성은 남지만 원문만으로 확인할 수 없다. 후보가 원문에 있다는 사실이나 접수 제품이라는 사실만으로 `supported`가 되지 않는다.
- 근거 문장 번호는 검수자가 판단에 사용한 원문 위치다. 문장 번호가 유효하다는 것은 의미 연결이 옳다는 증거가 아니다.

PC01 원문: “선풍기를 접수하려고 합니다. 선풍기 모터에서 연기가 났습니다.” 위험 사건 E는 2번 문장 “연기가 났습니다”다.

NC01 원문: “선풍기를 접수하려고 합니다. 타는 냄새가 납니다. 냄새가 어디서 나는지는 확인하지 못했습니다.” 위험 사건 E는 2번 문장 “타는 냄새가 납니다”다.
