# A/S 관계 탐색: 새 발화 문장·경로 검토 초안

아래 V01–V16은 **AI 작성 초안**이며 아직 사용자가 검수하지 않았고 모델에도 보내지 않았다. 같은 위험 표현에서 지시 대상이나 발생 여부를 바꾸는 대조쌍을 포함한다. 접수 대상 제품에 실제 위험이 발생하면 즉시 보호, 소유·발생이 불명확하면 안전 확인, 다른 출처 또는 미발생이면 일반 수집으로 제안했다. 문장·경로가 채택된 뒤 제품·위험 근거 번호와 모든 상태 필드를 별도로 검수해야 한다. 채택 전에는 모델 실행과 성능 집계를 하지 않는다.
