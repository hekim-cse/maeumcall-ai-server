# A/S 관계 탐색: 새 발화 문장·경로 검토 초안

아래 V01–V16은 **AI 작성 발화**다. 사용자가 2026-11-09에 문장과 기대 경로를 탐색용으로 채택했고, [별도 검토표](nlu_safety_relation_v2_field_review.md)의 제품·위험 근거 번호와 전체 상태 필드도 채택했다. 아직 모델에는 보내지 않았다. 같은 위험 표현에서 지시 대상이나 발생 여부를 바꾸는 대조쌍을 포함한다. 접수 대상 제품에 실제 위험이 발생하면 즉시 보호, 소유·발생이 불명확하면 안전 확인, 다른 출처 또는 미발생이면 일반 수집으로 판단했다. 노출된 RE 사례의 [함의 후보 개발 점검](nlu_safety_entailment_exposed_development_result.md)에서 해당 후보를 미채택해, 새로운 후보를 결정하기 전까지 V 사례를 보존한다.
