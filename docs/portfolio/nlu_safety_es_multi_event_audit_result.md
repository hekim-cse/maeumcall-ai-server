# A/S ES 전체 후보의 복수 사건 규칙 재평가 결과

[평가 방법](nlu_safety_es_multi_event_audit_method.md)과 실행 코드를 `926e262`에 고정했다. 이전 ES 감사와 같은 검수 사건 19개와 원문 후보를 사용했다. 관찰 18개와 불확실 1개를 평가했고 미발생 사건 3개는 제외했다. 이전 감사의 두 규칙 결과와 사건별 후보 수·정답 후보 ID가 저장본과 일치했다.

| 지표 | 이전 기기 조작 | 시간·후속 행동 | 새 복수 사건 |
| --- | ---: | ---: | ---: |
| 정답 출처 정확 선택 | 0/18 | 0/18 | 0/18 |
| 정답 후보가 목록에 없음 | 0/18 | 0/18 | 0/18 |
| 정답 후보가 있었으나 보류 | 18/18 | 18/18 | 18/18 |
| 정답 대신 다른 출처 단독 선택 | 0/18 | 0/18 | 0/18 |
| 검수 출처 공란을 올바르게 보류 | 1/1 | 1/1 | 1/1 |
| 복수 승인 | 0/19 | 0/19 | 0/19 |
| 판별 오류 | 0/19 | 0/19 | 0/19 |

정답 출처 18개가 모두 제공 후보에 있었다. 후보 미생성과 한도 탈락은 각각 0건이다. 이전 기기 문맥 규칙도 표와 같은 결과였다.

- **ES02**는 `오늘` 접두사가 새 경계 검사를 통과한다. `식기세척기 전원선`에서 Kiwi가 `전원`과 `선`을 분리하며, 현행 물리 부위 근거가 이 구절을 받지 못한다.
- **ES06**은 별개 두 사건을 서술하지만 완료 조치 없이 `불꽃이 튀었고`로 이어진다. 복수 사건 규칙이 받는 완료 조치 구문과 다르다.
- **ES14**의 `그 옆의`는 시간 접두사가 아니고, `전원을 뺐어요`는 현재 후속 행동 패턴 밖이다. `무선 충전 패드`도 물리 부위 근거 범위 밖이다.

[ME 대조에서 개선된 결과](nlu_safety_multi_event_action_pair_result.md)는 해당 대조의 고정 후보 결과로 남는다. 기존 ES의 전체 후보 감사에서는 개선이 관찰되지 않았다. ES에는 검수 사건 구절과 발생 상태가 입력되므로 서비스 종단 간 안전이나 실사용 성능을 이 수치로 평가할 수 없다.

[후보별 결과](../../evals/structured_nlu/results/as-safety-es-multi-event-development.v1.json)는 `python -m scripts.audit_as_safety_es_multi_event`로 재현한다. Kiwi 및 사전 모델은 각각 0.23.2, 0.23.0이다. 새 결과와 이전 감사의 기본 출력을 각각 저장본과 바이트 단위로 비교했다.
