# 내부 test 문장 독립성 재검토: 교체 후보 6건

> **실모델 실행 전 AI 작성 교체 문장 검수 기록.** IT01–IT64와 SS01–SS16의 1차 문장·방향을 채택한 뒤, 기존 탐색 자료와의 의미 유사성 감사에서 아래 여섯 건을 교체했다. 사용자는 교체 문장과 표의 라벨 방향을 채택했다. 이후 최종 데이터·프로토콜을 동결하고 [노출 재검사](nlu_internal_test80_exposure_audit_v1.md)와 [실모델 평가](nlu_internal_test80_verified_result.md)를 완료했다. 저장소 밖의 과거 노출이나 모든 의미상 바꿔쓰기가 없음을 증명하지는 못한다.

IT27은 별도 문제였다. 출발 여부 질문은 과거 검수 NS13에서 정규화 가능한 목표가 공란이었고, 이 경우 현재 `provide_details` 계약에 필요한 새 필드가 없다. 처음 제안한 현재 위치 질문도 같은 새 test의 IT25와 지나치게 비슷해 폐기했다. 사용자는 최종적으로 IT27을 “지연이 계속되면 상담원과 통화하고 싶습니다.”로 바꾸고 `delay_resolution=agent_handoff`로 평가하는 안을 채택했다. 상담원 연결이 이미 완료됐다는 뜻은 아니다.

SS13도 별도 문제였다. 물에 닿지 않았다는 진술만으로 모든 안전 이상이 없다고 단정할 수 없어, 사용자는 `safety_status=null` 수정안을 채택했다.

채택된 문장 원본·필드 검토표를 함께 수정했다. 이 문서는 데이터·프로토콜 동결이나 성능 수치가 아니다.
