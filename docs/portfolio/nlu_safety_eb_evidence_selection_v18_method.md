# A/S 번호 근거 선택 개발 진단

v17에서는 Q5가 자유 인용을 8회 모두 공란으로 반환했다. v18에서는 원문 문장 전체를 등장 순서대로 번호화한다. 사건 E와 판단할 후보 B는 기존과 같다. 모델은 출처 근거·배제 근거·불확실성 근거마다 번호 하나 또는 `null`을 반환한다. 번호를 원문 문장으로 되돌려 기존 관계 도출 규칙을 적용한다.

- **후보 포함률**은 검수된 정답 문장 번호가 실제 선택지에 들어 있는지 모델 호출 전에 사례별로 한 번 센다. 모든 원문 문장을 후보로 올리므로 이 표본의 포함률은 후보를 추려내는 능력을 측정하지 않는다. 정답 범위는 문장 번호까지다.
- **조건부 선택률**은 정답이 포함된 호출 중 최종 관계 판단에 사용된 문장 번호가 맞은 비율이다. 공란과 오류는 그 분모에서 실패로 센다. 실행 중단으로 호출하지 않은 행은 미실행으로 별도 기록한다. 관계 상태의 정답 일치와 출력 계약 오류도 별도로 집계한다.
- 같은 기노출 네 쌍에서 질문 정방향·역방향을 후보별로 한 번씩 실행한다. 질문 세 줄의 순서 외에는 두 조건의 요청이 같다. v17과는 요청 문구와 스키마가 함께 달라지므로 두 버전의 차이를 한 요소의 효과로 해석하지 않는다.
- 코드와 요청 해시, 모델, 이미지, 호출 순서를 호출 전에 커밋한다. 전송·출력 계약 오류 발생 시 기록 후 중단하고 재시도하지 않는다. 조건별 상태와 근거 문장이 각각 4/4이고 오류가 0건일 때 새 미노출 검증을 검토한다. 원문·판정 계약 범위의 개발 진단이다.
