# 내부 test 신규 발화 IT33–IT64: 사용자 문장·업무 방향 검토 초안 B

> **AI 작성·사용자 문장/방향·전체 필드 검수 완료, 모델 미실행.** 이 표는 16개 상세 업무 내부 test 64건 중 뒤쪽 8개 업무의 문장 32건이다. 사용자가 [IT40·IT41 교체 문장과 라벨 방향](nlu_internal_test80_independence_revision_review.md)까지 채택했다. [전체 필드 검토표](nlu_internal_test64_field_review_part_b.md)의 행동·비공란·공란도 채택했지만 아직 동결된 평가 데이터가 아니며 성능 분모에 넣지 않는다. 모든 등장인물·주문번호는 가상이다.

각 업무는 시작 상태에서 업무 안·범위 밖 각 1건, 실제 후속 상태에서 업무 안·범위 밖 각 1건이다. 후속 상태의 두 문장은 **서로 다른 독립 대화**에 같은 상태 조건을 적용한 후보이며 한 대화의 연속 발화가 아니다.

**입력 계약 주의:** 배달·시청의 네 업무는 적은 `current_fields`의 나머지 필드를 `null`로 채워 평가 입력에 전달한다. 예약 네 업무의 직접 분석기는 `current_fields={}`만 허용한다. 모든 업무에서 아래 직전 서버 질문은 해당 상태에 도달할 수 있음을 설명하는 **그래프 문맥 예시**이며, 현재 직접 분석기 입력에는 전달되지 않는다. 예약 항목의 이전 예약 정보도 전달되지 않는다. 따라서 후속 발화는 직전 질문을 보지 않아도 의미가 드러나도록 제안했다. 사용자가 검수할 때 이 한계를 함께 판단해야 한다.

## 검수 전 확인할 경계

- IT35·IT39·IT43·IT47은 현재 필드가 실제 평가 입력에 전달되는지 확인한다. 모든 후속 사례의 직전 질문은 평가 입력에 없다. IT51·IT55·IT59·IT63은 이전 예약 정보도 없으므로 **상태 이름과 사용자 발화만으로** 행동·필드 정답을 검수한다.
- IT43의 온라인 신청 자격은 여권 재발급 업무 안이지만, 모델이 실제 자격을 판단하거나 신청을 처리하는 일은 이 구조화 추출 평가의 대상이 아니다.
- IT54·IT56은 의료 판단을 요청하는 범위 밖 사례다. 모델 응답의 의료 정확성이나 안전성 평가는 이 시험의 대상이 아니다.
- 문장·방향 검수 뒤에만 행동 코드와 모든 필드의 값·공란을 별도 검토표로 만든다. 그 전에 모델에 입력하지 않는다.

계약 근거: `services/flow/delivery/contracts.py`, `services/flow/cityhall/contracts.py`, `services/flow/reservation/{hair_salon,hospital,study_room,restaurant}/llm_structured.py`; 후속 질문은 각 서비스의 응답 정책과 수집 상태 정의를 확인했다.
