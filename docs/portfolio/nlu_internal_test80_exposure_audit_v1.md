# 내부 test 80건의 기존 사례 노출 점검

> **범위가 있는 사전 점검, 실모델 미실행.** 새 test 64건(IT)과 별도 안전 16건(SS)을 개발 validation 뒤에 작성했다. 사용자는 문장·방향·전체 필드와 아래 교체안을 채택했다. 이 문서는 저장소 안에서 확인 가능한 사례와의 중복 위험을 기록한다. 저장소 밖의 과거 호출이나 모델 학습 데이터까지 검사한 증명서는 아니다.

## 검사 범위와 방법

1. `evals/structured_nlu/data`의 JSON/JSONL에 있는 이전 `user_message`와 validation 32건을 `NFC+strip`한 원문 해시로 비교한다. 평가 도구의 `known-nlu-corpus-inventory-v1.json`은 이 저장소 데이터 범위의 정확 일치만 검증한다.
2. `docs/portfolio`의 기존 문장 초안과 이전 평가 사례도 사람이 읽는 형태로 대조한다. 문장 자체가 달라도 **같은 사건·업무·판단 경계**를 되풀이하면 독립 사례로 보기 어렵기 때문이다. 이 단계의 최초 후보 탐색과 비교표는 AI가 수행했고, 사용자는 변경 후 문장과 라벨 방향을 검수했다. 저장소 전체의 모든 의미상 바꿔쓰기에 대한 사람 전수 보증으로 표현하지 않는다.
3. 마지막으로 새 묶음 내부의 유사성도 점검한다. IT27의 첫 교체 제안은 IT25와 같은 현재 위치 질문이어서 폐기했다.
4. 로컬에 보존한 2026-11-17 validation·PF 실행 기록 120개 파일을 읽어, 최종 IT+SS 80개 발화의 NFC 정규화 원문 UTF-8 바이트가 기록 안에 통째로 나타나는지 검사했다. **일치 ID는 0개**였다. 원문 기록에 사용자 발화가 저장되지 않았을 수도 있으므로 이 검색만으로 과거 모델 미노출을 증명하지 않는다. 원문 내용은 출력하거나 이 문서에 복사하지 않았다.

## 발견과 처리

| 새 ID | 가까운 기존 사례 | 중복 위험 | 사용자 채택 후 처리 |
| --- | --- | --- | --- |
| IT05 | [F03](nlu_scope_fresh_ai_review.md) | 청구서의 결합 할인 0원과 할인 조건 문의가 가까움 | 새 가족 결합의 할인 조건 상담으로 변경 |
| IT17 | [B09](nlu_broad_ai_exploration_review.md), [C09](heldout_nlu_ai_candidates.md) | 과제 제출 방식 문의의 구조가 비슷함 | 자료구조 트리 순회 구현 방식 질문으로 변경 |
| IT40 | [F20](nlu_scope_fresh_ai_review.md) | 깨진 유리의 생활폐기물 배출 질문과 가까움 | 텃밭 흙 배출 질문으로 변경 |
| IT41 | [B21](nlu_broad_ai_exploration_review.md), [C21](heldout_nlu_ai_candidates.md) | 미성년 자녀 첫 여권의 구비서류 문의와 가까움 | 긴급여권 접수기관 문의로 변경 |
| SS15 | 기존 `EG26` | 가정형 충전 스파크·접수 절차 질문과 가까움 | 스크루 변형 걱정과 명시적 미발생으로 변경 |
| SS16 | 기존 `EG22` | 안내문 속 연기 가정과 다른 고장 문의가 가까움 | 칼날 노출 부정과 고장 접수로 변경 |
| IT27 | 기존 `NS13`; 새 IT25 | 출발 여부는 현행 정답 코드가 없고, 첫 교체안은 IT25 위치 질문과 반복 | 지연 지속 시 상담원 연결 희망으로 변경; `delay_resolution=agent_handoff` |

SS15·SS16의 EG 원문은 `evals/structured_nlu/data/ai_heldout/as-safety-event-gate-fresh-reviewed.v1.json`, NS13의 검수 판단은 [기존 필드 검토표](nlu_scope_fresh_v2_field_review.md)에 있다. 교체 문장과 라벨은 [교체 검토표](nlu_internal_test80_independence_revision_review.md)에 남겼다.

교체안 6건의 `NFC+strip` 원문은 대조한 기존 문서·데이터 파일에서 일치하지 않았고, AI의 표적 의미 대조에서도 거의 같은 사건·판단을 발견하지 못했다. IT27의 최종 문장도 IT25와 다른 필드와 후속 행동을 평가한다. 이 결과는 검토한 파일과 비교 방법에만 유효하다.

## 평가 발행 전 남은 확인

- 최종 JSON 64+16건을 확정한 뒤 **동일한 원문·내부 중복 검사**를 다시 실행하고 검사 대상 파일·해시·결과를 기록한다. 교체 전 초안의 검사 결과를 최종 데이터의 결과로 대체하지 않는다.
- 2026-11-17 로컬 보존 실행 기록의 원문 부분 문자열 검사는 위 범위에서 완료했다. 그 밖의 비공개 과거 실행 기록과 저장소 밖 노출은 현재 목록에서 확인할 수 있는 범위만 점검한다. 확인하지 못한 범위는 `확인 불가`로 남긴다.
- 의미 유사성의 판단과 사용자 1인 검수를 명시한다. AI 작성·사람 검수 내부 표본이라는 출처를 보존하며, 사람 직접 작성 표본이나 외부 공식 벤치마크로 부르지 않는다.
