# 새 구조화 NLU 사례 사람 검토 기록 양식

이 양식은 [AI 초안 후보 36건](heldout_nlu_ai_candidates.md)의 개발 진단 메모용이다.
현재 모든 칸은 비어 있으며 **승인이나 정답 확정 기록이 아니다**. 각 후보에서
아이디어를 쓸지 판단하고, 사용할 경우 사람이 새 발화를 직접 작성한다. 해당
발화의 현재 상태·이전 필드·정답 전체·태그·판단 근거는
[`annotation-guideline.v1.md`](../../evals/structured_nlu/guidelines/annotation-guideline.v1.md)에
따라 별도 source와 검수 원장에 기록한다. 아래 표만 채워서는 `adjudicated`
상태가 되지 않는다.
이 36건은 이미 Q5 모델로 탐색 실행했으므로 독립 test로 재사용하지 않는다.

`판단`에는 `아이디어 사용 후 재작성`, `수정 후 재검토`, `제외` 중 하나를 쓴다.
`새 문장/정답 위치`에는 실제 작성 파일과 case ID를 적는다. 의미가 갈린다면
`근거·남은 쟁점`에 적고 확정 전에는 모델 테스트에 넣지 않는다.

모든 새 발화·정답이 검수되면 split 배정과 데이터 지문을 **모델 실행 전에**
고정한다. 그 뒤 같은 case ID 집합에 기존·수정 방식을 각각 실행한다. 검수 전의
AI 제안이나 탐색 실행 결과를 최종 정확도 개선율로 사용하지 않는다.
