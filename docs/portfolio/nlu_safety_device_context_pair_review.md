초안은 후보 20개 중 승인 4개, 보류 16개다. 관찰 장소 분모는 DC04-1·DC05-1·DC06-1 세 개다. 채택 뒤 기존 조합 규칙과 새 규칙을 같은 후보에 적용해 누락·오승인·두 후보 전체 일치·오류를 비교한다. AP09와 AP10은 회귀 참고에만 쓰며 새 표본의 분모에 넣지 않는다. 채택 전에는 이 표본을 판별기에 실행하지 않는다.
