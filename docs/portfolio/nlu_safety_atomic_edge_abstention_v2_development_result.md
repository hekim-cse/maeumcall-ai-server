## 실행과 재검증

- [사전 설계](nlu_safety_atomic_edge_abstention_v2_method.md)의 A/B 문구만 달리하고 같은 Kanana Q5·출력 스키마·요청 설정에서 ES01·03·09·17·18을 각각 한 번씩 호출했다. 고정된 순서의 10건을 완료했고 재시도·전송 오류는 없었다.
- 실행 코드·방법은 커밋 `7d1e0df206048531e91a76cf467ba5b55c05b6ac`에서 고정했다. [프로토콜](../../evals/structured_nlu/data/ai_heldout/as-safety-eb-abstention-v2-development-protocol.json)의 SHA-256은 `fa7a2f574220e7fb92275277895d5aa14c14f12434cf715c7fdb8aa8702de56c`이며, 10개 요청 본문 각각의 해시를 호출 전에 기록했다. 모델 파일 SHA-256은 `644b04cde835d486df33c6d4d7552ba367fcb28802fe39b6b4bb9c60b9ab6f3d`, 컨테이너 이미지 digest는 `sha256:17155a3ce4cc906728ec99a2814bf0b4eaffaf3b4872bad8c3affed310cdbc35`다. 로컬 컨테이너는 CPU 2개·메모리 4 GiB·127.0.0.1 전용 포트로 실행했다.
- [공개 저널](../../evals/structured_nlu/data/ai_heldout/as-safety-eb-abstention-v2-development-journal.v1.jsonl)의 SHA-256은 `804c1c1f64545e7f883ed783ffecdd67b8d89908dd3b055104e24b43925c0b3b`다. 원문·프롬프트·응답은 저널에 넣지 않았고 원시 응답 10개는 저장소 밖 권한 제한 폴더에 보관했다.
- 독립 검증기는 원본 19건의 프로토콜·저널 해시와 원시 응답을 먼저 확인한 뒤 새 10건의 요청 해시, 순서, 원시 응답 해시, 출력 계약과 정답 집계를 재계산했다. 새 A 조건 5건은 원본 첫 실험의 같은 사례 응답과 **각각 정확히 일치**했다. 원시 응답 10개도 모두 같은 SHA-256 `5be97f81196e53142824ded6069f25888525a7df59d8d97cef1488454932fa64`의 `unresolved`·두 `null`이었다. 실행 후 로컬 컨테이너와 Docker Desktop을 종료했으며 AWS·KT cloud는 사용하지 않았다.
- PR 리뷰 후 실행기에서 중복 프로토콜 키·저널/원시 응답 경로 충돌을 거부하고 호출 사이 컨테이너 ID·시작 시각을 확인하도록 보강했다. 검증기는 불리언 사건 번호를 거부하고 잘못된 모델 응답을 집계하는 회귀 테스트를 추가했다. **이 수정은 실모델 실행 뒤** 이뤄졌으며 원본 프로토콜·저널·원시 응답은 바꾸지 않았다. 따라서 수정된 실행기를 원본 프로토콜의 실행 코드라고 주장하지 않는다. 보강한 검증기 SHA-256은 `bb0be4b598711de5ac0d28d9153243f20a5015978e1dc6774b419d396045c03b`이고, 모델 재호출 없이 같은 집계를 재현했다. 관련 오프라인 테스트 40개와 Ruff를 통과했다.

두 조건 모두 5건에서 전건 보류했고 결과의 차이가 없었다. **이번 한 문장 수정은 해당 5건의 보류를 해소하지 못했다.** A가 원본 응답을 재현했으므로 실행 환경 변화로 A/B 차이를 설명할 필요도 없지만, 이 결과만으로 보류의 원인을 특정하거나 문구가 일반적으로 무관하다고 단정할 수는 없다. 계약 5/5는 공란 형태의 유효성이지 주체 추출 성공이 아니다.

기존 19건 실험은 개발 관문을 통과하지 못했다. 이번 5건 비교는 그 관문을 평가하지 않았고, B→A 관계·최종 안전 경로도 평가하거나 서비스에 연결하지 않았다. 다음 진단에서는 **출력 스키마**와 **근거 동시 요구**를 각각 별도 변수로 분리해, 명시 주체를 찾는지와 ES17에서 정당하게 보류하는지를 함께 확인한다. TX·GB 봉인 자료는 사용하지 않는다. 새 후보의 성능 주장은 코드·조건 고정 뒤 모델에 노출되지 않은 별도 검수 사례가 있어야 한다.
