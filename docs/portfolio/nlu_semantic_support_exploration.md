# NLU 필드 의미 지지 여부 탐색

2026-11-05에 [근거 위치 실험](nlu_source_evidence_exploration.md)의 한계를
확인하려고, 별도 Q5 모델 호출이 발화·필드·후보 값·인용문의 **의미 관계**를
판정할 수 있는지 탐색했다. 서비스 코드나 실제 응답 경로는 바꾸지 않았다.
발화에 인용문이 존재하는지만 보는 방법과 `supported`·`contradicted`·
`insufficient`를 고르는 모델 판정을 구분했다.

[개발용 주장 6건](../../evals/structured_nlu/data/exploratory/semantic-support-claims-2026-11-05.json)은
이미 모델에 노출된 F17·D05·F23·F29에서 만들었다. F17의 재배달 요청,
D05의 환불 가능 여부, F29의 날짜 공란은 사용자가 경계 판단을 명시했다.
F23의 플랫폼 공란과 나머지 값은 AI 필드 초안을 탐색용으로 채택한 수준이다.
주장 조합과 인용문 선택도 AI 작성 진단 자료다.
공식 평가 정답이나 새로운 사람 작성 테스트가 아니다.

모든 주장에는 원문에 정확히 한 번 존재하는 인용문이 있다. 이는 입력 조건이다.

| 방법 | 탐색용 기대 판정과 일치 |
| --- | ---: |
| 인용문 존재만으로 지지한다는 단순 규칙 | 3/6 |
| Q5 별도 의미 판정, 주장당 1회 | 3/6 |

Q5는 6건 모두 `supported`라고 답했다. `S01` 재배달 희망, `S05` 주민등록등본,
`S06` 오전 10시는 탐색용 기대 판정과 일치했다. 그러나 `S02`의 환불 **가능 여부**를
환불 희망으로, `S03`의 일반적인 **온라인** 발급을 특정 플랫폼으로,
`S04`의 **평일**을 확정 예약일로 인정했다. 세 경계 중 D05와 F29는
사용자가 공란을 명시했고, F23은 탐색용 초안에서 공란이다. 단순 규칙과
별도 Q5 판정 모두 이 세 경계를 구분하지 못했다. 기대 판정은 기존 탐색용
필드 초안으로 정했으며 `contradicted` 사례는 포함되지 않았다. 모델을
한 번씩 호출한 작고 이미 노출된 개발 자료이므로 일반적인 판정 성능
차이로 해석하지 않는다.

[실행 보고서](../../evals/structured_nlu/results/exploratory-q5-semantic-support-2026-11-05.json)는
주장 ID, 탐색용 기대·실제 판정, 토큰 수, 소요 시간, 입력과 코드 해시만 담는다.
발화·프롬프트·완성 답변·인용문 전문은 저장하지 않았다. 실행 당시 코드의
[스냅샷](../../evals/structured_nlu/candidates/semantic-support-probe-v1.txt)을
따로 보존했다. 로컬 Q5 GGUF SHA-256은
`644b04cde835d486df33c6d4d7552ba367fcb28802fe39b6b4bb9c60b9ab6f3d`,
서버 이미지 digest는
`sha256:17155a3ce4cc906728ec99a2814bf0b4eaffaf3b4872bad8c3affed310cdbc35`였다.
Docker CPU 4개·메모리 6GiB·스레드 4개·단일 슬롯·컨텍스트 4096,
`temperature=0`, `max_tokens=100`, JSON 객체 제약으로 실행하고 종료했다.

실험 후 확인한 원본 발화 문서, F 필드 초안, D 초안의 SHA-256은 각각
`a819c794ba9cc18bb39e722275be0724323268b5c6a7b933fe7cd1a175b9a4d1`,
`4920a9149195022089bc1e2da6e81f00aa3d580a68007e3ab6aee347e84bd0d1`,
`c7151d8051a5fbc857a6246c8e8ea2706314d23ff096ec092d7dc08396948357`이다.
F·D 로더의 SHA-256은 각각
`7b802a3e91a540b60c34ef83b0c3c483c35030029e04c53d67f929583a44f11e`,
`d94003ad3598b91028cc0da328b3ae3fcc7a4d5da57393e51019af88878a7f18`이다.
이 다섯 해시는 원 실행 보고서에는 들어 있지 않다. 이후 재실행용 스크립트에
입력 파일 해시 기록을 추가했으며, 원 실행 보고서의 코드 해시와 결과는
바꾸지 않았다.

**판단:** 인용 검사는 의미 검증이 아니며, 같은 Q5 모델을 한 번 더 부르는
방식도 이번 세 경계 오류를 찾아내지 못했다. 이 판정기를 서비스에 적용하지
않는다. 다음에는 의미 정책과 후보 방식을 먼저 고정하고, 모델에 노출되지 않은
사람 작성·검수 사례에서 기존 방식과 짝지어 비교해야 한다. 그 전에는
포트폴리오의 정확도 개선율 또는 운영 성능 수치로 사용하지 않는다.
