# NLU 알려진 원문 목록 V1

> 2026-11-16. 이 목록은 새 validation·test의 **정확 일치 중복 점검**을 위한 보수적 입력이다. 과거 모델 호출 전체의 완전한 기록이나 의미상 유사 문장 부재의 증거가 아니다.

[해시 목록](../../evals/structured_nlu/data/ai_heldout/known-nlu-corpus-inventory-v1.json)은 `evals/structured_nlu/data`의 JSON·JSONL에서 비어 있지 않은 `user_message`를 찾고, 현재 내부 validation 초안·채택본은 제외해 만들었다. 발화가 있는 원본 **53개 파일**의 SHA-256과 원문을 NFC 정규화·양끝 공백 제거한 뒤 계산한 **서로 다른 발화 해시 334개**를 정렬해 보존한다. 원문 발화는 이 목록에 다시 복사하지 않는다.

검수된 내부 validation 32건을 같은 방식으로 대조했을 때 정확히 겹친 ID는 **0건**이었다. 이 검사는 목록에 포함된 저장소 파일과 동일한 원문만 잡는다. 이전 모델 호출에 쓰였지만 저장소에 없는 문장, 다른 표현으로 바꾼 문장, 정답 의미의 중복은 별도 사람이 검토해야 한다. validation은 후보 선택용이며 최종 내부 표본 test와 혼동하지 않는다.

평가 전에 목록 파일 자체와 `source_files`의 원본 파일 해시를 프로토콜에 동결한다. 원본이나 정규화 규칙을 바꾸면 이전 점검 결과를 그대로 재사용하지 않는다.
