# A/S 후속 행동과 두 번째 사건 출처 대조 초안

AI가 작성한 새 발화 9개에서 사건을 지정해 11개 대조쌍을 만들었다. 각 행은 지정한 사건에 대해 원문 후보 두 개를 승인 또는 보류하는 판단이다. 같은 발화를 다시 보는 행은 지정한 사건만 바꾼다. 쉼표로 연결된 구간은 기존 절 번호 규칙에 따라 모두 1번 절이다.

ME10은 지정 사건을 미발생으로 제안한다. 나머지 지정 사건은 관찰로 제안한다. ME07은 불꽃을 관찰했지만 실제 출처를 확인하지 못한 경우다.

- 후보 22개 중 승인 7개, 보류 15개다.
- 관찰 장소는 ME04-1·ME05-2·ME06-1·ME10-2의 4개다. ME10-2는 다른 사건을 목격한 장소다.
- 다른 사건의 실제 출처는 ME01-2·ME02-1·ME03-1·ME05-1·ME06-2·ME07-2·ME09-1의 7개다.
- ME02·ME05는 두 번째 사건을 지정한 별도 진단이다. 11개 사건 단위 집계와 함께 실제 두 번째 사건으로 이어지는 발화에서 첫 사건을 지정한 ME01·03·04·06·07·08·09의 결과를 따로 본다. 같은 발화를 재사용한 행은 독립 발화로 세지 않는다.
- 채택하면 사건·후보·정답과 집계 분모를 먼저 고정하고, 기존 결합 규칙과 새 사건 경계 규칙을 비교한다. 기존 AC05는 별도 회귀로 확인한다.
