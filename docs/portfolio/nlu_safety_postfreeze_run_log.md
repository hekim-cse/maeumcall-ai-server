**판단:** 이 후보를 안전 성능 개선으로 소개하거나 바로 배포할 근거가 없다. PF는 코드 고정 후 새로 작성했지만, AI 작성·1인 검수이며 앞선 개발 사례와 같은 위험 유형을 겨냥한 표적 스트레스 세트다. 실제 사용자 발화 분포나 전체 업무 정확도를 추정하지 않는다. PF도 이번 실행 이후 개발·회귀 사례로만 사용한다.

다음 설계는 위험 단어의 존재만 보지 않고, 실제 위험 **현상**, 현재 A/S **대상**, 발화의 **긍정·부정·가정·인용**을 분리해야 한다. 이 설계 역시 PF에 맞춰 개발한 뒤에는 별도의 미노출 사례로 다시 평가해야 한다.
