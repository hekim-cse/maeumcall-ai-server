# A/S 기기명과 부위 조합 오프라인 대조 결과

사용자가 [DP01~DP09 검수표](nlu_safety_device_part_pair_review.md)를 채택했다. DP05와 DP08은 두 후보 모두 보류, DP06의 독립형 차폐망과 DP07의 단독 집진판은 승인으로 확정했다. [정답 JSON](../../evals/structured_nlu/data/ai_heldout/as-safety-device-part-dp-reviewed.v1.json)과 평가 코드는 첫 채점 전에 `69788a8`에 고정했다. 장소 오승인 분모는 관찰 장소로 제안·채택된 DP04-1, DP05-1, DP09-2의 세 후보다.

| 지표 | 기존 문맥 규칙 | 새 조합 규칙 |
| --- | ---: | ---: |
| 실제 출처 누락 | 5/5 | 2/5 |
| 관찰 장소 오승인 | 0/3 | 0/3 |
| 전체 오승인 | 0/13 | 0/13 |
| 두 후보를 모두 맞힌 발화 | 4/9 | 7/9 |
| 실행 오류 | 0/18 | 0/18 |

제습기 냉각판, 전원 공급기 절연막, 공기청정기 집진망은 새 조합으로 출처를 승인했다. DP05 보관함과 DP08 후속 정정은 보류를 유지했다. DP06의 독립형 차폐망과 DP07의 단독 집진판은 직접 출처지만, 이번 방식이 확인하는 기기명과 부위의 조합이 없어 계속 누락됐다.

기존 CP07의 `인쇄기 집진판`도 별도로 재확인했다. 원문 조합 판별 자체는 통과하지만, 그 전에 Kiwi가 `집진판`을 `집(NNG)·지(VV)·ᆫ(ETM)·판(NNB)`으로 분석해 명사구 조건에서 보류됐다. DP 집계에는 포함하지 않았다. 후속 검증에서는 원문의 기기·부위 조합 근거를 형태소 분석 앞에서 사용할 수 있는지, 기존 조사·앵커·보류 검사를 유지하면서 확인해야 한다. 기기 이름이 없는 실제 출처는 별도로 해결해야 한다.

[후보별 결과](../../evals/structured_nlu/results/as-safety-device-part-dp-evaluation.v1.json)는 `python -m experiments.as_safety_device_part_evaluation`으로 바이트 단위 재현했다. 입력 SHA-256은 `a798ac839d0e21424f8542d1182f55cf208047b3e28ed804a5dd6ca1c60da6a7`이다. AI 작성·사용자 검수 오프라인 9건이며 사건·후보가 주어진 조건이다. 실제 통화나 안전 경로 성능은 평가 범위에 포함되지 않는다.
