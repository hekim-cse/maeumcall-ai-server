# A/S 안전 경로: 코드 고정 후 새 발화 검토 초안

**현재 상태: AI 작성 발화 16건의 문장·위험 방향과 전체 필드 정답을 사용자가 2026-11-07에 채택했고, [짝비교](nlu_safety_postfreeze_run_log.md)에 사용돼 모델에 노출됐다.** 안전 경로 후보 코드는 이 문서를 작성하기 전에 `24cbf80`으로 고정했다. SC·CX 개발 사례는 평가에 넣지 않았다. 아래 설계는 실행 전 기록이며, PF 사례는 향후 새 성능 평가에 재사용하지 않는다.

## 비교 범위

대상은 A/S 접수 `greeting` 상태와 같은 Kanana Q5 파일·요청 정책이다. 기준 코드는 PR #51 병합 시점 `58595de`, 후보는 `24cbf80`이다. 실제 위험 8건의 안전 상태 진입과 비위험 8건의 잘못된 진입을 각각 고정 분모로 보고한다. 전체 서비스 정확도나 실제 사용자 분포 성능으로 일반화하지 않는다.

## 검수할 판단

- PF03은 배터리 케이스 변형을 실제 배터리 위험의 충분한 단서로 볼지, PF07은 휴대폰 팽창을 안전 이상으로 볼지 확인한다.
- PF08의 피복 손상도 즉시 사용 중지 보호 경로에 속하는지 확인한다. 현재 코드가 인식하는지와 정답 판단은 별개다.
- PF13은 냄새가 있지만 A/S 대상인 헤어드라이어에서 나온 것이 아니다. 출처를 분리하는 판단이 맞는지 확인한다.
- 문장·방향을 수정할 경우 해당 수정본을 다시 확인한 뒤 전체 필드 정답을 검수한다. 모델 실행 전에는 평가용 정답을 코드에 반영하지 않는다.
