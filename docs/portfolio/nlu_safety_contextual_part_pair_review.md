# A/S 부위 원문과 문맥 근거 대조쌍 검수 초안

AI 작성 오프라인 대조 9건이다. 모든 E는 관찰된 사건으로 제안한다. 후보 승인은 해당 물체나 부위가 사건의 직접 발생 위치나 출처로 확인됐다는 뜻이다. 출처가 무엇인지 여러 물체 중 특정할 수 없거나 후보가 관찰 위치이면 보류한다. 연결 방식이 기준선의 처리 범위 밖이어도 의미상 명확하면 승인 정답으로 제안한다.
