## 결정과 다음 설계

**후보를 서비스에 연결하지 않는다.** 노출된 CF에서는 실제 위험 즉시 대응 10건을 유지했지만, 새 EG에서는 8건 중 5건을 확인으로 늦췄다. 사건 표현을 계속 열거하는 방식은 새 발화에 취약하고, 근거 문장에 사건이 있어도 그 출처가 현재 A/S 제품인지는 여전히 해결하지 못한다. 모델 단일 요청의 결과를 두 단계로 검증하는 구조 자체는 유효한 연구 대상이지만, 현재 어휘 게이트는 보호 경로로 채택할 근거가 없다.

코드 리뷰에서 추가로 확인한 실패 가능성은 위험 발생이 아닌 수리 가능성의 불확실성을 위험 불확실성으로 오인하는 경우, 부정된 발열을 실제 발열로 오인하는 경우, 실제 위험 보고 뒤에 붙은 수리비 질문 때문에 위험 보고를 무시하는 경우다. 동결된 후보와 결과는 보존한다. 다음 후보는 위험 사건·부정·질문의 대상 관계를 분리해야 하며 새 사례에서 다시 평가해야 한다.
