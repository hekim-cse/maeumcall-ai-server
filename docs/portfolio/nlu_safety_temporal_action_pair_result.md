# A/S 시간 표현과 후속 행동 출처 판별 결과

사용자가 [대조표 12건](nlu_safety_temporal_action_pair_review.md)을 채택했다. 원문 사건·후보·정답과 네 규칙을 실행 전 `6b91984`에 고정했다. 시간 경계는 지정한 시간 표현만 허용한다. 후속 행동 경계는 지정 사건 뒤에 이미 완료한 보호 행동 한 문구가 이어지고 절이 끝나는 경우를 허용한다. 시점이나 행동 대상은 출처 근거로 쓰지 않는다.

TP01–02는 시간 조건으로, AC01–02는 후속 행동 조건으로, MX01은 두 조건을 함께 적용해 회복했다. AC05의 실제 출처인 배터리 단자는 보호 행동 뒤에 두 번째 사건까지 이어져 보류됐다. 같은 문장에 있는 두 번째 사건의 출처 후보도 보류됐다. AC06은 검수 상태가 미발생인 통제 사례다. 후속 행동 경계가 미발생을 자체 탐지하는지를 이 사례로 판단하지 않는다.

관찰 장소 분모는 TP03-1·TP04-2·AC03-1·MX02-1이고 다른 사건 출처 분모는 TP04-1·AC05-1이다.
