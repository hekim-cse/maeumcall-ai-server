# A/S 위험 주체의 중립적 개체 연결 개발 진단

## 가설과 실행 경계

[이전 단일 관계 진단](nlu_safety_gold_owner_link_result.md)에서는 검수된 위험 주체 구절을 제공해도 다른 출처 6건을 모두 현재 제품으로 판단했다. 이번에는 위험·안전 경로를 모델의 질문과 출력에서 빼고, **위험 주체 구절 B가 접수 대상 A와 동일한 물건 또는 그 소속 부품·부위인지**만 물었다. 원문 전체와 검수된 대상·주체 구절 및 문장 번호는 제공했다. 발생 상태, 위험 사건 구절, 정답 관계와 연결 종류는 요청에 제공하지 않았다. 원문 전체에 들어 있는 위험 표현 자체를 삭제한 실험은 아니다.

기존에 여러 번 노출된 AI 작성·사용자 검수 RE/V 22건(`current` 16, `other` 6)을 사용했다. 위험 주체 구절이 없는 RE07·V09는 제외했다. RE06은 조건부 발생이며, V04는 이번 진단의 토스터 접수 해석을 따른다. 검수된 구절은 실서비스 입력에서 얻을 수 없는 **오라클 입력**이다. 결과는 서비스 경로 정확도나 공식 정확도가 아니다.

후보·실행기·독립 검증기와 테스트는 커밋 `892ccb2`, [실행 규약](../../evals/structured_nlu/data/ai_heldout/as-safety-entity-link-diagnostic-protocol.v1.json)은 커밋 `680ec09`로 모델 호출 전에 고정했다. 프로토콜 SHA-256은 `e03e6e7b06f90190d27361f5bf158d75c56a62ac58f806c8abeed7f9ba928fc5`다. 동일한 로컬 Kanana Q5, 이미지 digest, 2 CPU·4GB·4096 context·temperature 0 설정에서 ID 순서대로 각 한 번 호출했고 재시도하지 않았다. [45행 저널](../../evals/structured_nlu/data/ai_heldout/as-safety-entity-link-diagnostic-journal.v1.jsonl)의 SHA-256은 `47609940240d2113e2543cc157027c728451d397297eacfb70e96a904ac1e0e2`다. 저널에 원문·인용 구절·모델 응답 본문은 없다.

재현 검증 명령은 저장소 루트에서 `.venv/bin/python -m scripts.verify_as_safety_entity_link_diagnostic --protocol evals/structured_nlu/data/ai_heldout/as-safety-entity-link-diagnostic-protocol.v1.json --journal evals/structured_nlu/data/ai_heldout/as-safety-entity-link-diagnostic-journal.v1.jsonl`이다. 독립 검증기는 코드·입력 해시와 커밋 일치, 22건 순서·45행, 중복 JSON 키, 유한 오류 상태, 모델 판단과 사후 관계·경로 매핑을 다시 확인한다.

## 관찰값

| 검수 관계 | 정확한 개체 연결 | 출력 분포 |
| --- | ---: | --- |
| 현재 제품 `current` | 16/16 | `current` 16 |
| 다른 출처 `other` | 1/6 | `other` 1, `current` 2, `unknown` 3 |
| 전체 | 17/22 | 계약·호출 오류 0/22 |

다른 출처의 거짓 동일 판정은 RE09·RE11이고, 보류는 V02·V06·V08이다. 실제 발생이 관찰된 현재 제품 위험은 13/13을 동일 제품으로 연결했다. 그러나 타출처의 거짓 안전 경로 2건이 남고, V01/02·V05/06·V07/08 대비쌍에서 기대한 `current → other` 반전은 **0/3쌍**이다. 서로 다른 출력으로의 단순 변화는 3/3쌍이지만, 그중 타출처를 정답인 `other`로 확정한 쌍은 없다. 검수된 발생 상태를 모델 출력과 *사후 결합*한 오라클 파생 경로 일치는 17/22이며 실서비스 경로 점수가 아니다.

단일 실행 모델 호출 지연의 중앙값은 4,975.960ms, 최근접 순위 p90은 5,634.197ms였다. 프롬프트 길이와 출력 표현이 이전 진단과 달라, 지연 차이나 16/22→17/22의 차이를 인과적 개선으로 해석하지 않는다. 사례도 반복 노출된 개발 집합이다.

## 판단

사전 게이트는 현재 제품 최소 15/16, 관찰된 현재 제품 위험 13/13, 다른 출처 6/6, 기대한 대비쌍 반전 3/3, 오류 0/22였다. **다른 출처 1/6과 기대 반전 0/3으로 실패했다.** 중립적인 단일 질문만으로 타출처를 충분히 구분한다는 가설은 이번 조건에서 기각됐다. 모델의 내부 원인을 특정하거나 일반화된 정확도 개선율을 주장할 수 없다.

새 GB01–GB24는 이번 후보 설계·실행에 사용하지 않았고 모델에도 보내지 않았다. 이 후보를 서비스에 연결하거나 GB 탐색 평가에 올리지 않는다. 다음 개발에서는 RE09·RE11의 거짓 동일 판정과 V02·V06·V08의 보류 원문을 분리 분석하고, 접수 대상의 소유·소속 연결 근거를 별도로 검증할 수 있는 후보를 설계한다. 새 후보는 기노출 사례의 안전·출처 게이트를 통과한 뒤에만 GB 입력에 적용한다.
