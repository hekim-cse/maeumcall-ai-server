# 범위 밖 발화 판단 지시문: Q5 짝 실험

2026-11-04에 16개 구조화 NLU 업무의 AI 작성 개발 사례 32건을 사용해 Q5
GGUF의 기본 지시와 범위 판단을 명시한 지시를 비교했다. 사용자는 이 문장과 행동
방향을 **탐색용으로** 채택했다. 정규화 필드 값은 미검수 AI 초안이다. 이 실험은
모델에 이미 노출된 문장을 사용했으므로 공식 정확도, 새로운 사례로의 일반화,
배포 효과를 측정하지 않는다.

추가 지시는 “현재 업무와 직접 관련 없는 질문이나 요청은 구체적인 정보가 있어도
현재 업무의 정보 제공으로 분류하지 말고 `unknown`과 null 필드를 반환”하도록
시스템 메시지에 한 문단을 더했다. 서비스 코드는 변경하지 않았다. 두 조건은
같은 Q5 파일과 `llama.cpp` 이미지, 로컬 ARM CPU 4개·스레드 4개·단일 슬롯·
6GiB 메모리 제한·컨텍스트 4096·동일 요청 설정에서 실행했다. 32개 문장 각각에
기본→추가 지시 순서로 실행하고, 두 번째 반복에서는 사례와 조건 순서를
뒤집었다. 따라서 아래 분모 32는 **16개 고유 문장을 두 번 관찰한 값**이다.

| 관찰 항목 | 기본 지시 | 범위 판단 추가 지시 |
| --- | ---: | ---: |
| 전체 출력 계약 통과 | 48/64 | 53/64 |
| 계약 통과와 탐색용 행동 방향 동시 일치 | 32/64 | 40/64 |
| 범위 안 발화의 계약·행동 동시 일치 | 30/32 | 30/32 |
| 가까운 범위 밖 발화의 계약·행동 동시 일치 | 2/32 | 10/32 |
| 범위 밖에서 두 반복 모두 동시 일치한 고유 문장 | 1/16 | 5/16 |
| 필수 필드 누락으로 계약 실패 | 14/64 | 7/64 |
| JSON 키 불일치로 계약 실패 | 0/64 | 2/64 |

짝 비교에서 추가 지시만 계약·행동 방향을 함께 맞힌 관찰은 B02·B06·B18·B30의
각 2회, 총 8회다. 기본 지시만 맞힌 관찰은 없었다. 기본 조건의 범위 밖 성공은
B26 두 번뿐이었다. 추가 지시에서도 16개 범위 밖 문장 중 11개는 두 반복 모두
계약·행동을 함께 맞히지 못했다. `action_missing_required_field` 실패는 줄었지만
JSON 키 누락 2회가 새로 나타났다. **이 지시를 서비스에 적용하지 않았다.**

완주한 [원시 관찰 및 집계 보고서](../../evals/structured_nlu/results/exploratory-q5-scope-instruction-2026-11-04.json)는
사례·반복·조건별 계약 결과, 안전한 출력 형태, 오류 코드, 토큰 수와 실행 조건,
입력·모델·이미지·코드 지문을 기록한다. 사용자 발화나 모델이 생성한 값 전문은
저장하지 않는다. 실행 도중 CPU 2개 조건의 불완전한 기록은 비교에서 제외하고,
두 조건 모두 CPU 4개로 처음부터 다시 실행했다. 요청 시간은 토큰·캐시·재시도
차이가 있어 속도 우열로 해석하지 않는다.

포트폴리오에는 “16개 업무의 범위 밖 발화를 짝 실험으로 분석해, 추가 지시가
이미 관찰한 개발 사례에서 행동 오판을 일부 줄였지만 11/16개 문장은 여전히
실패해 배포를 보류했다”는 식으로 **탐색 진단과 배포 판단**을 설명할 수 있다.
정확도 개선율을 쓰려면 새 독립 사례와 사람 검수 정답을 동결한 뒤 동일한 두
조건으로 다시 평가해야 한다.
