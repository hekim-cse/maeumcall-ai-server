# 업무 범위 프롬프트 개발 진단

이 기록은 이미 Q4/Q5 모델에 노출된 AH01–AH32를 Q5로 다시 실행한
**개발용 진단**이다. 새 평가 성능이나 포트폴리오의 정확도 개선율로
사용하지 않는다. 원본 예측과 실행 설정은
`evals/structured_nlu/results/ai-heldout-q5-scope-dev-2026-11-06.json`에
보존했다. 모델 출력 원문과 프롬프트는 저장하지 않았다.

| 지표 | 이전 Q5 | 공통 업무 범위 문구 추가 |
| --- | ---: | ---: |
| 전체 행동 일치 | 16/32 | 17/32 |
| 전체 완전 일치 | 1/32 | 2/32 |
| 범위 밖 행동 일치 | 0/16 | 2/16 |
| 범위 밖 최종 계약 통과 | 10/16 | 14/16 |
| 업무 안 행동 일치 | 16/16 | 15/16 |
| 업무 안 완전 일치 | 1/16 | 0/16 |

범위 밖의 일부는 개선됐지만 업무 안 사례에서 행동 일치와 완전 일치가
하락했다. 따라서 공통 문구만으로 성능 개선을 주장할 수 없다. 이어지는
수정안은 각 업무의 지원 목적을 명시한다. 이 선택은 위 개발 진단에
근거하며, 새 NS01–NS32 평가 사례는 수정안 선택에 사용하지 않는다.
