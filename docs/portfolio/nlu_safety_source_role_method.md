# A/S 관찰 장소와 변화 주체 오프라인 대조

기존 EP 평가에서 장소 두 건을 실제 출처로 잘못 승인했다. 새 후보는 관찰 사건의 단순 긍정문에서 Kiwi가 확인한 명사 주어, 주격 조사, 변화 동사를 연결한다. 팽창·갈라짐·녹음·휘어짐에서 별도로 표시된 장소보다 변화한 주어를 우선한다. 지각 동사나 후속 발화의 명시적인 출처 미확인 표현이 있으면 보류한다. 다른 구문에는 기존 조사 기준선을 적용한다. 이 방식은 명시한 변화 동사와 보류 표현만 처리하는 부분 규칙이며, 제품 종류별 장소 목록이나 외부 모델을 추가하지 않는다.

새 AI 작성 개발 대조 SL01~SL08에서 같은 사건과 후보를 두 버전에 입력한다. 정답은 입력과 코드를 고정한 뒤 채점에만 사용한다. `observed`는 사건을 보았거나 보고했다는 조건이며, 출처가 확인됐다는 뜻은 아니다. 양성 누락과 음성 오승인을 분리해 집계하고, 두 후보를 모두 맞힌 발화 수와 실행 오류도 남긴다. 특히 명시적인 불확실성 단서가 없는 장소 사례와 수리 장소만 불명확한 대조를 포함한다.

이 표본은 EP 결과에서 확인한 실패 유형을 바탕으로 만들었다. AI 작성 개발 표본의 짝 비교이며 실제 통화, 독립 홀드아웃, 안전 경로 성능의 추정치는 아니다. 기존 EP 정답·결과와 서비스 경로는 별도다.
