# A/S 번호 근거 선택 모델 대조

Kanana Q5는 [v18](nlu_safety_eb_evidence_selection_v18_result.md)의 네 후보 쌍, 두 질문 순서에서 8회 모두 보류했다. 같은 번호 선택 요청에서 다른 모델도 전건 보류하는지 확인한다.

대조 모델은 [Qwen2.5-1.5B-Instruct Q5_K_M 공식 GGUF](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/blob/dd26da4/qwen2.5-1.5b-instruct-q5_k_m.gguf)로 고정한다. 한국어를 지원하고, 기존 로컬 실험과 같은 GGUF 양자화 종류를 사용할 수 있어 선택했다. 비교 단위는 모델 파일과 그에 따른 내장 채팅 템플릿·토크나이저를 함께 포함한다. 가중치만의 효과나 논문 벤치마크의 우위를 추정하지 않는다.

- 동일한 v18 요청 본문, 출력 스키마, 호출 순서, 컨테이너 이미지와 서버·생성 설정을 사용한다. v18에 고정된 요청 해시 8개를 실행 전에 대조한다.
- 기존 Kanana 결과를 참조하고 Qwen만 새로 호출한다. 실행 날짜와 캐시 상태가 달라 지연의 우열 또는 같은 날의 짝 비교로 해석하지 않는다.
- 정답 후보 포함 여부, 포함 조건의 정답 근거 선택, 계약 오류, 상태 일치, 공란 응답을 각각 집계한다. 네 쌍은 기노출 자료다. 오류를 기록한 뒤 생성 호출을 멈추며 재시도하지 않는다.
- 두 순서 모두에서 근거와 상태가 각각 4/4이고 계약 오류가 없을 때에만 새 미노출 평가를 검토한다. 전건 공란이 반복돼도 두 모델과 이 네 쌍에서만 성립하는 관찰이다. 서비스 경로는 이번 비교의 평가 범위 밖이다.
