**상태: AI 작성 개발 사례 16건의 문장·안전 판단을 사용자가 2026-11-07에 채택, 모델 미노출.** 코드 작성자가 이 문장을 보고 규칙을 개발하므로 CX 사례는 이후 미노출 성능 평가의 분모에 넣지 않는다. 행동·전체 필드 값과 공란은 아직 검수하지 않았다. 이전 RF·SC 사례도 이미 모델에 노출돼 새 점수에 합산하지 않는다.

## 평가 질문

## 검수할 기준

- `위험 있음`은 현재 A/S 대상 제품에서 사용 중지 안내가 필요한 현상을 실제 관찰했다고 말한 경우다. 다른 제품·타인의 후기·가정·부정은 현재 제품의 확정 위험으로 취급하지 않는다.
- CX03의 연무와 CX04의 배터리 덮개 변형, CX05의 불꽃은 안전 우선의 충분한 근거인지 검수한다. 의미가 애매하면 문장 또는 방향을 수정한다.
- 이 후보들은 안전 경계 평가를 위한 AI 작성 문장이다. 독립적인 실제 사용자 분포를 대표하지 않으며, 사용자의 검수만으로 모델 성능 수치가 생기지 않는다.
