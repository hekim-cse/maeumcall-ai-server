# 새 A/S 안전 출처 경계 발화 검토 초안

**상태: AI 작성·문장/기대 방향 사용자 채택·전체 필드 미검수·모델 미실행.** 사용자가 2026-11-12에 수정된 GB01–GB24 초안의 진행을 요청했다. 기존 RE/V 문장의 재점수에 사용하지 않는다. 접수 대상, 위험 사건, 위험 주체의 원문 구간과 모든 상태 필드·공란은 [별도 검토표](nlu_safety_source_boundary_field_review.md)에서 확인받는다. 그 전에는 모델에 실행하지 않는다.

여기서 `일반 접수`는 **현재 접수 제품의 A/S 안전 경로**를 뜻한다. 다른 기기의 위험에 대한 현실적인 안전 안내 필요성까지 평가하거나 생략하자는 뜻은 아니다.
