# A/S 안전 관계 새 탐색 발화 TX01–TX16: 검수 기록

## 평가 경계

아래 문장은 **2026-11-10 AI가 작성한 발화**다. 사용자가 같은 날 문장·경로와 [제품·위험 근거 및 전체 상태 필드](nlu_safety_transfer_fresh_field_review.md)를 탐색용으로 채택했다. 새 사례를 모델에 보내지 않았으며, 첫 호출 전 입력과 실험 조건을 별도로 고정한다. 앞선 RE·V 사례는 이미 모델에 노출됐으며 이 묶음에 재사용하지 않는다.

이 묶음은 제품의 지시 대상과 실제 위험 사건을 연결하는지 살피는 **표적 탐색** 후보이다. TX01–TX08은 같은 고장·위험 표현에서 위험이 접수 제품에 속하는지 바꾼 네 대조쌍이다. TX09–TX12는 위험 출처나 발생 상태가 불확실한 경우, TX13–TX16은 현재 제품의 실제 위험 보고가 없는 경우다. 4개 경로 구간을 같은 크기로 두어 전체 일치율뿐 아니라 실제 위험 누락과 다른 출처 오분기를 각각 보려는 설계다. AI 작성·1인 검수라 채택 후에도 공식 전체 정확도는 아니다.

## 검수 및 실행 경계

1. **문장과 기대 경로 방향**을 먼저 검수했고, 이어 제품·위험 근거 문장 번호, 관계, 발생 상태를 별도 표로 검수했다. 검수된 값을 평가 입력 JSON에 고정했다.
3. **TX 사례로 후보를 선택하지 않는다.** 기존 RE·V만 개발용 원인 분석에 쓰고, 새 후보가 정해진 뒤 TX의 첫 모델 호출 전에 프로토콜을 고정한다.
4. 후보·요청 정책·입력·프로토콜·실행기·검증기 해시를 첫 호출 전에 고정한다. 새 사례는 각 방식에 한 번씩만 보내고 오류도 분모에 포함한다.

사전 지표는 현재 제품 실제 위험의 즉시 보호, 다른 출처의 잘못된 즉시 보호, 불확실한 사건의 확인, 미발생 사건의 불필요한 확인, 계약 오류, 호출 횟수와 지연이다. 총 일치율만으로 후보를 채택하지 않는다.
