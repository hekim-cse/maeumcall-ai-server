# A/S 시스템 지시 반응 별도 통제 검사

> 2026-11-24. v14가 첫 호출에서 출력 계약 오류로 중단되어 두 번째 호출은 수행하지 않았다. v14 프로토콜·저널·원시 응답을 보존하고, 미실행 시스템 지시 통제를 **새 프로토콜 하나**로 사전 고정한다. 이 검사는 의미 정확도 평가가 아니다.

원문·고정 후보 PC01/P014·사건·Q5 파일·서버 이미지·요청 설정·JSON 스키마를 [v12](nlu_safety_eb_pair_relation_v12_development_result.md)와 같게 둔다. 시스템 메시지 끝에만 “사건 의미와 무관하게 `unsupported`·2번을 반환”하라는 인위적 지시를 추가한다. 이 답은 원래 검수 정답과 다르므로 **모델이 진실을 맞히는지**가 아니라 명백한 지시 변화에 반응하는지 관찰한다. 독립 검증기가 시스템 메시지 외 모든 요청 JSON 값이 v12와 같음을 확인한다.

기존 v14의 부분 실행 해시를 검증한 뒤 코드·요청 바이트·토큰 수·모델·이미지를 생성 전에 별도 커밋에 고정한다. 한 번만 호출하고 재시도하지 않는다. 전송·길이·출력 계약과 `unsupported`·2번 이행을 분리 보고한다. 이행하지 않아도 시스템 메시지를 아예 받지 못했다는 뜻으로 단정하지 않는다. AI 작성·기노출 한 사례이므로 공식 정확도·개선율, 서비스 안전 경로 성능에 사용하지 않는다. AWS·KT cloud는 사용하지 않는다.
