# 독립 구조화 NLU 테스트: 사람 작성 발화 접수표

이 표는 **새 발화를 받기 위한 빈 작업지**다. 아직 테스트 데이터, 사람 검수 정답,
정확도 결과가 아니다. `H01`~`H36`은 작성 슬롯 번호이며 실제 case ID가 아니다.
작성자는 각 칸에 가상의 새 문장을 직접 쓰고, 이전 개발 자료 또는
[`AI 후보 36건`](heldout_nlu_ai_candidates.md)의 문장이나 가까운 바꿔쓰기를 피한다.
실제 사용자 대화와 개인정보는 사용하지 않는다.

정보 제공 발화는 해당 업무에 필요한 새 정보를 말한다. 어려운 발화는 해당 업무와
다른 요청, 부정, 모호한 의사 등 현재 상태에서 행동 판단이 필요한 문장으로 만든다.
예약 후속 발화는 앞선 턴에서 수집된 값도 함께 적어야 의미가 정해진다. 문장만
먼저 작성해도 된다. 그 뒤 AI가 상태·정답 **초안**을 만들면 작성자가 문장 의미와
모든 정답 필드를 직접 확인·수정한다. 모델을 실행하기 전에 split, 검수 원장,
데이터 지문을 확정한다. 이미 탐색 실행한 문장은 최종 독립 test에 쓰지 않는다.
