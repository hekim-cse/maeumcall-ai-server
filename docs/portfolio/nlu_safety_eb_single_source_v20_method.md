# A/S 번호 근거 단일 질문 개발 대조

Qwen의 [기존 v19](nlu_safety_eb_evidence_model_comparison_v19_result.md)에서는 세 근거가 모두 공란이었다. 이번에는 같은 네 후보에 출처 근거 질문만 적용한다. 원문 후보 목록, 사건 E, 후보 B, 출처 항목의 정수·공란 선택지, 모델 파일과 실행 환경은 유지한다. 사용자 지시의 범위와 스키마 필드 수는 함께 달라진다. 기준선은 v19 정방향 네 호출이다.

정답이 있는 출처 후보 PC01/P014에서 2번을 선택하는지 **1건**, 나머지 세 후보에서 출처 근거를 공란으로 두는지 **3건**을 나누어 보고한다. 정답 문장이 선택지에 있는지는 양성에서 따로 확인한다. 배제 근거와 출처 불확실성 근거는 이 단일 질문의 채점 범위 밖이다. 기존 관계 정답은 점수에만 사용하고, 같은 출처 질문을 네 경우 모두에 적용한다.

첫 생성 전에 코드·입력·순서·모델 해시를 커밋한다. 전송·계약 오류 시 중단하고 재시도하지 않는다. 양성 근거 1/1, 나머지 적절한 공란 3/3, 계약 오류 0건이면 다른 두 질문의 분리 검증으로 확대할 근거가 생긴다. 기노출 네 쌍의 단회 진단이다.
