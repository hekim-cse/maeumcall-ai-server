# A/S 위험 출처 2단계 조건 분리 개발 진단 결과

2026-11-15에 이미 노출된 AI 작성·사용자 검수 ES01–ES20을 [사전 설계](nlu_safety_stage2_ablation_v1_method.md)대로 로컬 Kanana Q5에서 다시 실행했고, 11월 16일에 독립 검증과 문서화를 마쳤다. 기존 조건은 검수된 사건·발생 상태를 입력하고 위험 주체 인용과 관계를 함께 출력했다. **R**은 주체 인용 출력을 없애 관계만 받았고, **O**는 기존 공동 출력을 유지하며 검수된 위험 주체 구절을 입력에 추가했다. 관계·경로 코드는 어느 조건에도 직접 제공하지 않았다. 단 O의 검수 구절 자체가 관계를 강하게 암시할 수 있다. 검수 주체가 공란인 ES17은 O에서 호출하지 않았다.

코드·방법 고정 커밋은 `fb84dedeae061672f0fe839ae8ff550f5b52f5d2`, [프로토콜](../../evals/structured_nlu/data/ai_heldout/as-safety-stage2-ablation-v1-development-protocol.v1.json) 커밋은 `9293f4d5d7fa7f7a677c031d5e86524d67731f76`다. 프로토콜 SHA-256은 `5737c40bd4264db6ec890552d817013bd4bebf193e67aa0c330b7c144b397f79`이다. 직전 진단의 비공개 원시 응답도 실행 전에 독립 재검증했고, 저장된 기준선과 일치했다. 모델 파일·llama.cpp 이미지·CPU 2개·4GiB·컨텍스트 4096·온도 0·요청 정책은 직전 조건과 같다. 각 적격 사건에 한 번 호출했고 재시도·중단 재개는 없었다.

**두 조건 모두 사전 안전 문턱에 실패했다.** R은 19개 사건을 모두 `other`로 출력했다. 다른 출처 관계 9/9와 전체 관계 9/19만 보면 좋아 보이지만, 현재 제품의 관찰된 위험 **8/8을 모두 안전 우선 경로에서 놓쳤다.** 출처 불명 ES17과 발생 불확실 ES18도 확인 경로 대신 일반 접수로 갔다. R의 전체 경로 10/20에는 모델을 호출하지 않은 ES19·20의 일반 경로 2건이 포함된다. 다른 출처에 대한 직접 오경고는 0건이지만, 이는 한 방향 출력과 함께 나타난 값이다.

O는 관계 5/18, 모델 관여 경로 5/17이었다. 유효 출력 13건은 `other` 9건, `current` 4건, `unknown` 0건이었다. ES01·09·10·12·14의 다섯 호출은 위험 주체 인용을 1번 문장으로 지정했지만 인용 문구는 실제 2번 문장에 있어 `quote_unanchored` 계약 오류로 거부되고 안전 확인 경로로 처리됐다. 이는 저장된 출력의 공통 형태이며 검수 주체 힌트가 오류의 원인임을 증명하지 않는다. 검수 주체 구절을 입력으로 제공해도 출력 계약과 관계 판단이 안정되지 않았다. O의 전체 경로 8/20에는 **모델 미호출 ES17·19·20**의 결정적 경로가 포함되므로 모델 판단 점수로 사용하지 않는다. 현재 제품의 실제 위험 8건 중 6건은 안전 우선 경로를 놓쳤다.

R의 9/19를 기존 7/19보다 높아진 정확도로, O의 5/18을 독립 모델 성능으로 해석하지 않는다. R은 기존 대비 ES10·11·12·15의 경로가 맞게 바뀌었지만 ES02·06은 틀리게 바뀌었다. O는 ES04·15가 맞게, ES02·09·14가 틀리게 바뀌었다. 순변화만으로 안전 방향을 판단할 수 없는 이유다. R은 출력 계약과 지시문이 바뀌었고 `other`만 선택했으며, O는 관계를 암시할 수 있는 정답 주체 구절을 받았다. 세 조건 모두 같은 **이미 노출된** AI 작성 문장에 대한 단일 실행이다. 이번 결과에서 확인할 수 있는 것은 인용 출력 제거만으로 안전 경계를 복원하지 못했고, 주체 구절 제공만으로도 계약 오류와 관계 오판이 남았다는 점이다. 각 조건의 시간 차이를 원인이나 실서비스 속도 개선으로 해석하지 않는다.

R의 요청 지연 중앙값·95백분위는 4,668ms·5,249ms, O는 5,323ms·5,730ms다. 사례 전체 지연 중앙값·95백분위는 R 4,657ms·5,250ms, O 5,197ms·5,731ms다. 무호출 사례가 사례 지연 분포에 포함되고 모델 로드 시간은 포함되지 않는다.

TX·GB 봉인 자료는 후보 선택에 사용하지 않았다.
