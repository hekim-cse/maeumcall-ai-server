# 탐색용 D05·F23 의미 판단 수정 기록

2026-11-05에 사용자가 새 SB 사례를 검토하며 두 개발 사례의 판단을 수정했다.
**D05**의 “혹시 환불 가능하나요?”는 앞으로
`resolution_preference=refund`로, **F23**의 일반적인 온라인 발급은
`issuance_channel=government24`로 본다. 사용자 판단은 이 AI 작성 발화의
탐색용 라벨에 관한 것이며 공식 정답 확정이 아니다.

[버전 지정 수정 자료](../../evals/structured_nlu/data/exploratory/prior-meaning-amendments-2026-11-05.json)는
원본 개발 파일의 SHA-256과 이전 값·새 값을 기록한다.
[적용기](../../evals/structured_nlu/prior_meaning_amendments.py)는 원본 파일
지문을 확인한 뒤 **새 탐색 실행에만** 수정값을 적용한다. 이전 입력 파일과
이미 저장된 실행 보고서는 바꾸지 않았다. 따라서 이전 보고서의 초안 일치 수치와
필드 불일치는 **그 실행 당시의 라벨**에 관한 기록이며, 새 판단 기준의 성능
수치로 재해석하거나 포트폴리오 개선율로 사용하지 않는다. 이번 SB01–SB12
비교에는 D05·F23 자체를 포함하지 않는다.

F29의 일반적인 `평일`은 이전 사용자 판단대로 예약일 공란으로 유지한다.
새 SB08의 `매주 화요일`은 사용자가 예약 의사와 날짜가 충분히 드러난다고
판단했다. 서비스의 스터디룸 일정표는 현재 이용 날짜가 아닌 요청 시간으로
가용 여부를 조회하므로, 이 탐색용 날짜 판단을 반복 예약 처리 능력이나 실제
예약 가능 여부로 일반화하지 않는다. 반복 예약은 운영 적용 전 별도 상태·확인
흐름이 필요하다.
