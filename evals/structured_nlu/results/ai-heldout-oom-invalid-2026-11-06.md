# AI 작성 평가 1차 실행: 모델 비교 무효

이 기록은 사전 고정된 AH01–AH32를 로컬 Q4·Q5에 실행한 **실패 실행**의
감사 자료다. 정확도 결과나 Q4·Q5 우열의 근거로 사용하지 않는다.

- 입력 동결 커밋: `00fe1f3`; 노출 기록 커밋: `03a7b6d`.
- 두 모델에 각각 32건의 예측 파일이 만들어졌다.
- Q4는 32건 중 55회 시도에서 최종 계약 통과 17건이었고, 12개 사례에
  전송 오류가 있었다. 첫 전송 오류 사례는 AH21, 마지막은 AH32다.
- Q5는 32건 중 41회 시도에서 최종 계약 통과 26건이었고 전송 오류는 없었다.
- Docker Desktop 메모리 한도는 8GB였다. Docker 이벤트에서 Q4 컨테이너의
  `oom`과 종료 코드 `137`을 확인했다. Q5는 평가 후 정상 종료 코드 `0`이었다.
- 따라서 두 예측 파일은 [Q4 실패 실행](ai-heldout-q4-oom-invalid-2026-11-06.json),
  [Q5 동시 실행](ai-heldout-q5-oom-invalid-2026-11-06.json)으로 이름을 바꿔 보존했다.
  원래 평가 출력 경로에는 남기지 않았다.

Q4의 전송 오류를 모델 추출 실패로 세면 서버 종료가 정확도 차이로 섞인다.
동일 모델·동일 정답·동일 요청 정책으로 두 서버가 끝까지 살아 있는 재실행을
별도로 완료하기 전에는 쌍 비교 점수를 발행하지 않는다. 재실행 시 이 실패
실행과 로컬 Docker 메모리 변경을 결과 문서에 함께 공개한다.
