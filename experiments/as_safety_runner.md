# A/S 개발 실험 실행기

새 실험 모듈은 호출 이름, 메시지, JSON 스키마, 검증 함수와 기준 기록을 지정한다. `as_safety_runner.Experiment`가 실제 요청 바이트 구성과 사전 고정, 모델 호출, 오류 시 중단, 저널 기록과 원시 응답 재생을 맡는다. 모델 어댑터는 고정된 파일을 로컬에서 로드하고 호출 전후에 점검할 수 있는 서버를 제공한다. 공개 저널에는 해시와 실제 시도 결과를 남기고, 원시 응답은 저장소 밖에 보관한다.

1. 새 실험의 코드와 방법을 커밋한다.
2. 실험 모듈의 `prepare --model-path …`를 실행하고 생성된 프로토콜을 별도 커밋한다.
3. `run --model-path …`로 실행한 뒤 `replay`로 검증한다. 오류가 나면 생성 호출을 멈추고 남은 호출은 결과 분모에 넣지 않는다.
4. 결과 PR은 사전 고정 코드 커밋을 참조하므로 병합할 때 원래 커밋을 보존한다.

기존 v19–v22는 당시 실행기와 프로토콜의 해시를 유지한다. 각각 기존 재생 명령을 사용하며, 공통 실행기는 이후 실험의 진입점이다.
